# IPTV Familial - Public APK releases

This repository contains public Android APK releases and the **complete corresponding source archive for each version**. The private development repository, test machines, signing keys, user IPTV accounts and secrets are not published.

**Licence:** GPL-3.0. IPTV Familial is a derivative of IPVIO Stream and contains third-party GPL-3.0 components. The source archive, license, build scripts and third-party notices are included as a download beside every APK in each release.

Releases: https://github.com/Ongbak130/IPTV-Familial-Updates/releases

For each release, download:
- `IPTV-Familial-BETA-N.apk` for Android / Fire TV / Onn
- `IPTV-Familial-BETA-N-SOURCE.zip` for its matching source code (GPL-3.0)

The application checks this repository's public GitHub Releases API at startup without a token. It offers to download a newer APK, then asks Android to authorize installation. Install updates over the previous beta to preserve local settings, subject to the same APK signing certificate.

The corresponding source archive is deliberately not a complete copy of the private development workspace, Git history, user data or secrets.
